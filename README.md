# it-supply-control

Controle de estoque voltado para equipamentos de informática, com customização básica.

Ferramenta interna para gestão de suprimentos de TI: ciclo de vida de equipamentos,
fornecedores terceiros, chamados externos e usuários finais. Hospedagem prevista no Microsoft Azure.

## Situação

Fase inicial: apenas estrutura do projeto e documentação. Ainda não há código da aplicação.

## Organização do repositório
