# Frontend

Aplicação React + TypeScript criada com Vite. **Ainda não criada.**

Será gerada com `npm create vite@latest` depois que o básico de JavaScript e React for estudado.
Estrutura prevista:

```
frontend/src/
├── app/          rotas, layout, providers
├── features/     assets/, supplier-exchanges/, master-data/
├── components/   componentes de interface reutilizáveis
├── lib/          cliente da API, funções auxiliares
└── styles/
```
