# Cadastros de apoio

Todos os campos categóricos são escolhidos de **listas fixas**, para impedir inconsistências
(por exemplo, "Dell", "DELL" e "dell" como marcas diferentes).

| Lista | Campos |
|---|---|
| Sites | Nome, endereço, Cnpj |
| Fornecedores | Nome, endereço |
| Tipos | Nome (iniciais: desktop, notebook, celular, tablet, monitor) |
| Marcas | Nome |
| Modelos | Nome, marca, tipo |

As listas são mantidas na tela **Cadastros de apoio**. No MVP qualquer utilizador pode incluir
itens. Ao cadastrar um ativo, a lista de modelos é filtrada pela marca e pelo tipo escolhidos.
